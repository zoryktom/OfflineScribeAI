# Data card (Gebru et al. datasheet style)

## Motivation

Create a public, PHI-free encounter set so documentation-error methods can be run without clinic data use agreements.

## Composition

- 100 templated English encounters (`E001`–`E100`) in `data/synthetic/manifest.jsonl`.
- Fields: transcript, gold SOAP, gold medications, gold entities, planted tokens (negation, laterality, medication).
- Specialties rotate: primary care, ortho, ENT, pulmonary, urology.
- No real names, MRNs, or recordings of patients.

Seed annotation JSONL files are derived from planted tokens. They are not double-annotated human labels.

## Collection

Generated by `src/offlinescribe/eval/synth.py`. No crowd workers. No patients.

## Preprocessing

Text is ASCII-friendly English. De-ID regexes in `src/offlinescribe/io/deid.py` are for fixture tests (MRN-like strings, dates), not for real charts.

## Uses

Intended: ablation of conditions in `docs/study_design.md`, CLI tests, CI.  
Not intended: pretraining, clinical decision making, or claims about real clinic prevalence of errors.

## Limitations

Templates repeat. Lexical overlap between transcript and gold is high by construction. WER between gold and stub drafts is not ASR WER on audio. English only.
